# Domain docs

This is a single-context repository.

Before exploring domain behavior, read these when they exist:

- `CONTEXT.md` at the repository root
- ADRs under `docs/adr/` that touch the area being changed

If they do not exist, proceed silently. `/grill-with-docs`,
`/domain-modeling`, and `/improve-codebase-architecture` create them only when
the project has real terminology or decisions to record.

Use the glossary's established terms rather than inventing synonyms. If a
proposal conflicts with an ADR, identify the ADR and make the contradiction
explicit instead of silently overriding it.
