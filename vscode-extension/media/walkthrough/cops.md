# `/cops`

Run this in your Copilot CLI session:

```
/cops
```

It opens **your project** and **the session folder** side by side in one
workspace — so the plan the agent is working from, its checkpoints and its task
list are all right there, in the window you were already using.

Once it has run, the **porthole** icon in the activity bar comes to life:

- **Session** — which session, which branch, `plan.md`, checkpoints
- **Tasks** — the agent's todo list, grouped by status
- **Tours** — walkthroughs of your code, once you ask for one

---

`/cops dry-run` shows exactly what it would do — which editor, whether it
reuses this window, every path — without opening or writing anything.
