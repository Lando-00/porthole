# Two halves

porthole is a **Copilot CLI plugin** and **this VS Code extension**, working
together. On its own, this extension has nothing to talk to.

In a terminal:

```shell
copilot plugin marketplace add Lando-00/porthole
copilot plugin install porthole@porthole-marketplace
```

Then start Copilot CLI in a project:

```shell
copilot
```

This step ticks itself off as soon as a Copilot CLI session tells this window
it is there.
