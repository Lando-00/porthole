# See it on your own code

```
/porthole example
```

Rather than a canned demo, this asks the agent to walk **you** through **your**
project — picking something real, marking it up, and explaining what it is
doing as it goes.

The fastest way to understand what porthole is for is to watch it happen on
code you already know.

---

## The rest

| Command | What it does |
|---|---|
| `/porthole help` | Every command, with examples |
| `/porthole` | Diagnose everything, when something is not working |
| `/tours` | The walkthrough library |
| `/vsdiff` | Diffs: uncommitted, a commit, a range, or two files |
| `/goto <file:10-25>` | Select and highlight a range |
| `/goto <symbolName>` | Select a whole function or class by name |
| `/problems` | What VS Code is reporting right now |
| `/diagram` | Describe it, get a rendered mermaid diagram |

And from in here, `Ctrl+Alt+.` sends the selected code straight back into the
session as a question.
